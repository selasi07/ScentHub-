# AI Usage Log

This document records the use of AI assistance during the development and documentation of ScentHub.

## AI Usage Summary

AI assistance was used for:
- Project planning and task organization.
- Code review and debugging suggestions.
- Documentation preparation and improvement.
- Security and privacy threat brainstorming.
- Reviewing logging and observability practices.

All AI-generated suggestions were reviewed by team members before being incorporated into the project.

## AI Usage Log

| Date | Tool | Task | Output Used | Human Verification |
|---|---|---|---|---|
| 1st August 2026 | ChatGPT | Project planning and development support | Planning suggestions and implementation guidance | Reviewed against project requirements and existing code |
| 2nd August 2026 | Codex | Code review and debugging | Suggestions for backend, database and API improvements | Code was manually reviewed, tested and adapted to ScentHub |
| 5th August 2026 | Gemini | Documentation | Assistance with Sprint 3 and security/observability documentation | Final documentation was reviewed and adapted by the team |

## AI-Assisted Deliverables

AI assistance contributed to the preparation and review of:
-Project planning.
-Code improvement.

AI assistance did not replace developer review or testing.

## Verification Process

AI-generated suggestions were:
1. Reviewed manually by a team member.
2. Compared against the existing ScentHub requirements and architecture.
3. Adapted to fit the actual implementation.
4. Tested before being accepted into the project.
5. Rejected when suggestions were not appropriate for the project.

## Confidential Data Statement

No confidential client information, passwords, API keys, private credentials, or other sensitive secrets were provided to public AI tools.

## AI-Related Risks and Mitigations

| Risk | Mitigation |
|---|---|
| Incorrect AI-generated suggestions | Manual review and testing |
| Security mistakes in AI suggestions | Human security review before implementation |


## Responsibility Statement

The team remains responsible for all code, documentation, security decisions and project deliverables. AI was used only as an assistance tool, and final decisions and verification were performed by the team.
